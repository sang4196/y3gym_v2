# 통합 지점 둘러보기와 시설 사진 슬라이드

사용자 요청에 따라 홈의 지점 둘러보기와 시설 둘러보기를 한 구역으로 합쳤다. 지점 탭 아래에서 선택 지점의 이름·상세 링크·시설 사진과 설명을 함께 보여준다. 기존 A 방향과 본점·예시점 두 지점 예시를 유지한다. 2026-10-10 사용자의 “ㅇㅋ 이대로 가자”로 현재 방향을 확인받았다. 후속 요청으로 홈과 지점 안내 페이지의 푸터 메뉴는 지점 안내·소식 두 개로 정리했다.

- 후속 응답 “시설슬라이드 통과”로 확인받은 지점 안내의 자동 슬라이드를 사용자 요청대로 메인화면에도 동일하게 적용했다. 공통 렌더링 함수·CSS·JavaScript를 사용한다.
- 조작 버튼 없이 4.5초마다 600ms 동안 한 칸씩 왼쪽으로 이동한다. 모바일 스와이프와 사진 영역의 키보드 좌우 탐색을 유지한다. 마우스/키보드 조작 중에는 멈추며 동작 줄이기 설정에서는 수동 탐색한다.
- 지점 변경 시 해당 지점의 첫 사진으로 돌아간다. 선택 지점은 별도 안내·문의·소식·팝업과 홈 복귀 시 유지한다.
- 사진 한 장이면 정적으로 표시한다. 사진이 없으면 사진 영역을 만들지 않고 상세 링크를 남긴다. JavaScript 실패 시 모든 지점·사진 목록을 표시한다.
- 홈과 지점 안내 모두 PC 3장·태블릿 2장·모바일 1장 배치와 사진 3:2 비율을 공유하고 각 사진 아래에 설명을 표시한다. 홈은 별도의 시설 구역 제목과 표면 경계를 두지 않는다.
- 첫 소개 영역의 ‘시설 사진 보기’는 ‘지점 안내’로 바꾸고 선택 지점의 `branches.html?branch=...`로 연결했다. 별도 지점 안내 페이지의 시설 목록·트레이너·위치 상세는 유지한다.

[비교 화면](index.html)에 PC 1440×900, 모바일 375×812 첫 화면, 본점/예시점의 통합 구역, 두 번째 사진, 홈·별도 지점 안내 전체 캡처를 정리했다. 총 20장이다. 전체 캡처는 폭을 유지한 긴 실제 뷰포트로 촬영해 고정 문의 바를 맨 아래에 표시한다. 하단 가림은 정상 모바일 높이에서 별도로 검사한다.

`npm run review`의 [checks.json](checks.json)은 두 페이지 각각 320·375·768·1024·1280·1440px에서 글꼴·이미지·가로 넘침·버튼 잘림·고정 문의 바의 가림과 관련 탐색을 확인한다.

`node scripts/verify-states.mjs --branch-only`의 [branch-slide-checks.json](../states/branch-slide-checks.json)은 8개 검수 그룹의 결과다. 사진 순서·순환·키보드·실제 Chromium 터치 이벤트의 좌우 스와이프 및 세로 스크롤, 지점 전환 초기화, 사진 1장/0장, 지점 추가, 선택 지점의 링크, 빈 데이터·사진 실패·JavaScript 실패를 확인한다. 이전 전체 팝업 검수 결과와 개수를 합산하지 않는다.

자동 검사는 사용자 디자인 승인을 대신하지 않는다. 실제 기기·다른 브라우저·백엔드·관리자·실제 지도·문의 서비스는 이번 작업에 포함하지 않는다. 모든 사진과 운영 정보는 임시 예시다. 이전 홈·지점 안내 분리 캡처는 `../branch-pages/`에 보존한다.

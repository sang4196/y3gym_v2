  • “시설슬라이드 통과”로 확인받은 지점 안내의 슬라이드를 홈에도 동일하게 적용했습니다. PC 3장·태블릿 2장·모바일 1장 배치에서 버튼 없이 자동 이동하며 모바일 스와이프·키보드 좌우 탐색을 제공합니다.

  • 기본 예시는 본점·예시점 두 지점이며 모든 사진·이름·운영 정보는 임시 예시입니다. 실제 문의·지도 서비스는 연결하지 않았습니다.

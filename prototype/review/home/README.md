## 이번 구현

- 트레이너 2명: 4:5 사진과 소개를 나란히 배치한다. 사진은 가상의 합성 인물이며 이름·소개도 예시로 표시했다. 경력·자격을 만들지 않았다.
- 최근 소식 2건: 공지·이벤트의 제목, 요약, 예시 날짜를 익숙한 목록으로 표시한다. 실제 행사나 혜택을 만들지 않았으며 목록·상세 화면은 아직 연결하지 않는다.
- 위치와 문의: 지도 배치 영역, 예시 주소·운영시간, 실제 연락처 등록 전 상태를 표시한다. 문의 대상인 본점을 명시하고 버튼은 모의 동작만 제공한다.
- 푸터: 브랜드와 기본 구역 링크를 제공한다. 헤더의 트레이너·소식 메뉴도 해당 구역으로 연결했다.

## 기본 검수

Chromium에서 320, 375, 768, 1024, 1280, 1440px 폭을 확인했다. 이미지 6장·로컬 글꼴 로딩, 가로 넘침, 버튼 글자 잘림, 모바일에서 마지막 푸터 설명의 가림, hover와 키보드 포커스, 모바일 메뉴·화면 폭 변경, 각 구역의 내부 링크, 모의 문의의 지점 표기를 확인했다. JavaScript 비활성 상태에서도 본문·주소·연락처 등록 전 안내·기본 메뉴와 내부 탐색이 남는다.

검사 결과와 촬영 크기는 [checks.json](checks.json)에 기록한다. `HOME_REVIEW_PENDING`은 위 사용자 응답 전 촬영 당시의 상태다. 실제 기기 및 다른 브라우저 검수는 수행하지 않았다.

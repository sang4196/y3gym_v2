# 시설 자동 슬라이드와 소식 수정

사용자 응답 “글 목록 통과. 시설슬라이드 통과.”로 목록 밀도와 버튼 없는 시설 자동 슬라이드의 시각 확인을 받았다. 이어진 요청에 따라 지점 안내의 슬라이드를 메인화면에도 동일하게 적용했다. 사진 3:2와 설명, PC 3장/태블릿 2장/모바일 1장 크기를 공유하며 4.5초 대기·600ms 전환을 사용한다. 두 페이지는 공통 렌더링 함수·CSS·JavaScript를 사용한다.

2026-10-10 후속 응답 “ㅇㅋ 확인. 다음 진행하자”로 홈 적용 결과도 확인받았다. 이 승인 기록은 사용자 응답에 근거하며 기존 자동 검사 결과·캡처의 촬영 시각을 변경하지 않는다.

사용자 요청으로 일시정지·이전·다음 버튼을 제거했다. 모바일 스와이프와 사진 영역에 초점을 둔 키보드 좌우 탐색을 유지한다. 마우스·키보드 조작 중, 화면 밖, 비활성 문서와 선택하지 않은 지점은 자동 재생하지 않는다. 동작 줄이기 설정에서는 자동 재생을 끄고 수동 탐색을 제공한다. 지점을 바꾸면 첫 사진으로 돌아온다. 복제 사진은 보조기술과 키보드 탐색에서 제외한다. 0장/1장 및 JavaScript 실패 시 정적 그리드와 기본 본문·탐색을 유지한다.

`npm run review:gallery`로 홈과 지점 안내 각각의 6개 화면 폭, 자동 반복·정지·지점 전환·모바일 터치·반응형 전환·동작 줄이기·빈 사진/실패 상태를 검수하고 [checks.json](checks.json)에 기록한다. [검토 페이지](index.html)는 PC/모바일 캡처와 두 페이지의 실제 브라우저 자동 이동 영상을 제공한다. 전체 캡처는 같은 폭의 긴 뷰포트로 고정 문의 바를 아래에 둔다. 홈의 선택 지점 상세 링크와 모바일 문의·팝업 동선은 유지한다.

소식은 [기존 검토 페이지](../news/index.html)에 캡처를 제공한다. 승인받은 목록 행 여백은 PC 10px·모바일 8px이며 제목·설명 크기와 간격도 함께 조정했다. 상세 하단의 ‘지점 위치와 문의 보기’와 ‘목록으로 돌아가기’는 요청에 따라 제거했다. 상단 현재 위치의 소식 링크와 공통 메뉴는 유지한다.

# 시각 검토 기록

2026-10-09 사용자의 “ok확인 진행”으로 아래 1차 범위의 시각 확인과 홈 확장 진행을 승인받았다. 이후 **[홈 전체](home/README.md)도 사용자의 “확인” 응답으로 확인받았다. 현재는 [팝업·상태 검수](states/README.md)를 진행했다.** 아래 캡처와 `checks.json`은 1차 촬영 당시의 기록으로 보존한다.

## 1차 시각 검토 — 사용자 확인 완료

헤더부터 시설 사진 3장까지 구현한 A 방향의 시각 프로토타입이다. 사진은 합성 임시 이미지이며 주소·운영시간은 예시다. 문의 서비스는 연결하지 않았다.

| 화면 | 첫 화면 | 전체 구현 범위 |
| --- | --- | --- |
| PC | [1440×900](desktop-first.png) | [1440px 폭](desktop-full.png) |
| 모바일 | [375×812](mobile-first.png) | [375px 폭](mobile-full.png) |

전체 캡처는 같은 폭의 긴 뷰포트로 촬영했다. 모바일 고정 문의 바의 실제 위치는 375×812 첫 화면에서 확인하며, 끝까지 스크롤했을 때 마지막 설명이 가려지지 않는지도 별도로 검사했다.

## 기본 검수 결과

Chromium에서 320, 375, 768, 1024, 1280, 1440px 폭을 확인했다. 이미지 4장과 로컬 Pretendard 로딩, 가로 넘침, 버튼 글자 잘림, 모바일 하단 콘텐츠 가림 검사를 통과했다. 주요 버튼 hover, 키보드 포커스, 모바일 메뉴와 화면 폭 변경, 모의 문의 버튼도 확인했다. JavaScript 비활성 상태에서 본문·모바일 메뉴 목록·시설 내부 링크가 남는 것을 확인했다. 브라우저 스크립트 오류와 실패한 리소스 요청은 없었다.

기계 판독 결과와 캡처 크기는 [checks.json](checks.json)에 기록했다. 실제 모바일 기기 및 다른 브라우저의 검수, 팝업·다지점·전체 기능 회귀 검수는 아직 수행하지 않았다.

## 사용자 확인 항목

- 배경·흰색 표면·포인트색의 밸런스
- 사진의 분위기·크기·잘림
- 제목과 본문의 위계
- 구역 간 여백과 첫 화면의 밀도
- 문의 버튼의 강조 수준과 익숙한 사용감

**자동 검사 통과는 디자인 승인이 아니다.** 1차와 홈 전체는 각각 사용자 응답으로 확인했으며 팝업·상태별 화면은 새 캡처로 검토한다.

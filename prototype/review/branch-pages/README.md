# 홈 미리보기와 별도 지점 안내

사용자 응답 “배치 합격”으로 기존 통합 지점 탭의 배치 확인을 받았다. 이어진 요청에 따라 A 방향과 탭 스타일을 유지하고 홈과 상세 안내를 분리했다. 이 분리 화면의 시각 승인은 아직 대기 중이다.

- 홈: 브랜드 소개·지점 탭·짧은 소개와 상세 진입·시설 미리보기·공통 소식·푸터.
- `branches.html`: 지점 선택·주소/운영시간 요약·시설·소속 트레이너·위치와 문의.
- 헤더/푸터의 트레이너 독립 메뉴 제거. 지점 안내는 같은 탭의 별도 HTML 페이지로 이동.
- 홈 선택 지점은 상세 진입·문의·모바일 문의·소식·팝업 및 홈 복귀 시 URL로 유지.
- 지점 데이터는 두 페이지가 공유한다. 기본 예시는 본점·예시점 두 지점이다. 정적 목록을 추가하고 재생성하면 탭도 늘어난다.
- 실제 서비스 연결과 새로운 운영 사실은 추가하지 않았다. 모든 정보와 사진은 임시 예시다.

[비교 화면](index.html)에서 PC 1440×900과 모바일 375×812의 첫 화면, 두 지점의 홈·지점 안내 전체 캡처를 볼 수 있다. 총 18장이다. 전체 캡처는 같은 폭의 긴 실제 뷰포트를 사용해 고정 문의 바가 맨 아래에 오도록 촬영했다. 정상 모바일 높이의 본문 가림은 별도로 검사했다.

`npm run review`의 [checks.json](checks.json)은 홈과 상세 각각 320·375·768·1024·1280·1440px에서 글꼴·사진 로딩, 넘침, 버튼 잘림, 하단 가림을 확인한 결과다. 헤더의 페이지 이동, 선택 지점 유지, 홈 복귀, 모바일 메뉴·문의 바, 버튼 hover/focus도 확인했다.

`npm run review:states`의 [상태 검사](../states/checks.json)는 팝업과 선택 지점의 연결, 지점 추가, 빈 데이터·사진/지도 실패·JavaScript 실패 대체 동작을 포함한 16개 그룹을 확인한다. JavaScript 실패 시 홈과 상세 모두 일반 링크와 모든 지점 패널을 제공하며, 주소와 연락처는 상세 페이지에서 읽을 수 있다.

자동 검수 통과는 사용자 시각 승인이 아니다. 실제 기기·다른 브라우저·백엔드·관리자·실제 지도·문의 서비스는 이번 작업에 포함하지 않는다. 승인받은 이전 통합 탭의 캡처는 `../branch-tabs/`에 보존한다.

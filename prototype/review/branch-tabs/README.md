# 통합 지점 탭 시각 검토

사용자는 현재 PC 별도 창·모바일 레이어 팝업을 확인했고, 이후 지점 정보를 하나의 탭으로 묶도록 요청했다. 기본 예시는 본점·예시점 두 개를 유지한다. 이 문서의 캡처는 시각 승인 전 촬영 당시 이력이며, 이후 “배치 합격”으로 확인받았다.

홈 순서는 브랜드 소개 → 지점 탭 → 선택한 지점의 요약·시설·트레이너·위치와 문의 → 공통 소식 → 푸터다. 탭과 전체 패널은 `branch-data.js`의 같은 목록에서 생성하며 개수를 고정하지 않는다. 모바일에서 많은 탭은 탭 줄만 가로 스크롤한다.

초기 패널은 직접 연결한 지점 → URL의 branch → 같은 탭의 이전 선택 → 첫 지점 순서로 정한다. 지점 변경 시 네 구역이 함께 전환되고 헤더·푸터 탐색도 해당 지점을 따른다. 소식 글과 팝업에서 돌아올 때 명시한 선택을 유지한다. JavaScript 실패 시 일반 지점 링크와 모든 패널을 노출한다.

## 검수와 한계

[화면 검사](checks.json)는 Chromium에서 320/375/768/1024/1280/1440px의 이미지·글꼴·가로 넘침·하단 가림·기본 탐색을 확인한다. [전체 상태 검사](../states/checks.json)와 [지점 변경 후 관련 재검수](../states/branch-tab-checks.json)는 별도 보고서이며 합산하지 않는다.

지점 추가 검사는 기본 데이터를 수정하지 않고 메모리 안에서 일곱 개로 확장한 HTML을 브라우저에 제공한다. 현재 정적 프로토타입에서는 데이터 수정과 재생성으로 추가를 반영하며 실제 등록 API·백엔드·관리자는 구현하지 않는다. 시설·인물·주소·연락처·운영시간은 모두 임시 예시이고, 예시점은 합성 시설 사진을 재사용했음을 표시한다. 실제 모바일 기기와 Chromium 외 브라우저는 아직 확인하지 않았다.

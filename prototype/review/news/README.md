# 소식 목록과 공지·이벤트 상세

승인된 홈·지점 안내·시설 슬라이드·팝업 다음으로 공통 소식 화면을 정적 프로토타입에 추가했다. A 방향과 푸터의 지점 안내·소식 두 메뉴를 유지한다. 사용자 응답 “글 목록 통과”로 조정한 목록의 시각 확인을 받았다. 상세 하단 두 링크는 요청에 따라 제거했다.

- 전체/공지/이벤트 분류는 기본 HTML 링크다. JavaScript가 없어도 필터 페이지와 상세 본문을 읽을 수 있다.
- 목록은 날짜 최신순, 구분선이 있는 행으로 표시한다. 기존 공지·이벤트 예시 각 1건을 사용한다. 대표 사진이 없는 글에 빈 사진 자리를 만들지 않는다.
- 목록의 행 위아래 여백은 PC 10px·모바일 8px로 더 줄였다. 제목과 설명 간격 및 모바일 행 내부 간격은 2px다. 제목은 PC 18px·모바일 16px, 설명은 14px·줄간격 1.45, 분류와 날짜는 13px로 조정했다. 제목과 설명은 생략하지 않고 줄바꿈한다.
- 상세에는 분류·제목·등록일·문단·강조·소제목·목록을 표시한다. 사용자 요청으로 하단의 문의 버튼과 목록 복귀 링크를 제거했다. 기존 상단 현재 위치의 ‘소식’ 링크로 보던 분류/페이지에 복귀할 수 있고 공통 메뉴를 유지한다.
- 소식은 모든 지점 공통이다. 본점/예시점을 선택해도 글의 내용과 목록은 같으며 문의·다른 페이지로 이동할 때 선택 지점은 유지한다.
- 홈 최근 소식과 목록/상세는 `news-data.js`의 같은 데이터를 사용한다. 헤더·푸터의 소식 메뉴와 홈의 ‘소식 모두 보기’는 목록으로 연결한다.
- 목록 표시 수는 초기값 10건이다. 글이 많으면 정적 페이지 링크를 생성하며 1페이지만 있으면 페이지 이동을 숨긴다. 검수에만 23개 가상 글과 비공개 제외 표식을 추가했다. 기본 예시 데이터는 두 글이며 임의의 행사 혜택이나 실적을 만들지 않았다.
- 빈 목록은 안내 문구·분류·기본 메뉴를 제공한다. JavaScript 실패 시 기본 목록 복귀는 전체 목록으로 연결하며, 브라우저 뒤로가기는 방문했던 분류 페이지를 유지한다.

`npm run review:news`로 재생성하고 검수한다. [checks.json](checks.json)에 소식 목록·공지 상세·이벤트 상세·빈 목록 각각의 320/375/768/1024/1280/1440px, 분류/상세/복귀, 선택 지점, 페이지 이동, 비공개 예시 제외, JavaScript 대체 동작 및 리소스 오류 검수를 기록한다.

[검토 페이지](index.html)에 PC 1440×900, 모바일 375×812의 첫 화면과 전체, 검수용 페이지 이동을 포함한 17개 캡처를 제공한다. 전체 촬영은 같은 폭의 긴 뷰포트이며 문의 바가 맨 아래에 표시된다. 정상 높이에서의 가림은 별도로 검사했다.

현재 파일은 가상 공개 데이터의 정적 화면이다. 관리자·초안 편집·실제 공개 철회·서버 접근 통제·지도/문의 연동을 구현한 것이 아니다. 비공개 예시 제외 검수는 렌더링 입력의 구분만 확인한다. 실제 기기·Chromium 이외 브라우저는 아직 확인하지 않았다. 자동 검수는 사용자 시각 승인을 대신하지 않는다.

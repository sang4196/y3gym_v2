# 이전 두 지점 병렬 배치 캡처

본점·예시점 정보를 병렬로 노출하던 이전 배치다. 사용자 후속 요청으로 현재 홈은 통합 지점 탭으로 변경했다. [최신 탭 배치](../branch-tabs/README.md)를 확인하며 이 폴더는 이력으로 보존한다. 기존 사용자 확인을 받은 단일 지점 홈 캡처는 `../home/`에 있다.

- [PC 첫 화면](desktop-first.png) · [전체](desktop-full.png)
- [모바일 첫 화면](mobile-first.png) · [전체](mobile-full.png)
- [기본 화면 검사](checks.json)

이 촬영에서는 자동 팝업을 억제했다. 자동 열기·수동 열기·조건과 실패 대응은 별도의 [상태 검수](../states/README.md)에서 확인했다. 홈 확인과 새 팝업·상태 UI의 사용자 시각 검토는 구분한다.
